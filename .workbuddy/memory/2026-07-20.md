## 技术发现
- AgentPay 核心架构：FastAPI + SQLAlchemy + Web3.py + Solidity(Hardhat) + Streamlit + LangGraph
- 双轨结算：Track 1 SQLite（毫秒级即时记账）+ Track 2 Ethereum（去信任智能合约托管）
- 三条合约：EscrowPayment（CEI模式防重入）、ServiceRegistry（链上服务发现）、Reputation（防刷分评分）
- 三种认证：API Key / 飞书 App ID / OpenClaw Bot Token，token前缀自动路由
- 定价算法：关键词三级阶梯 ×0.4/×1.0/×2.0，过渡方案 → 规划中按LLM Token实际用量计价
- 飞书Webhook集成：自然语言触发 → 动态定价 → 支付 → 结算全自动闭环
- agentpay-skill CLI：CUA-driver macOS桌面自动化 + ETH钱包管理 + 订单轮询
